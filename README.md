# Personal Portfolio Website

## Overview
This is a responsive Personal Portfolio Website built using HTML, CSS, and JavaScript. The website showcases my skills, projects, education, and achievements as a web developer.

## Features
- Responsive Navigation Bar
- Hero Section with Profile Photo
- About Me Section
- Skills Section
- Projects Showcase
- Education Details
- Contact Information
- Modern and Responsive Design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Sections

### Home
Introduction with professional profile image and headline.

### About Me
Information about background, education, and career goals.

### Skills
Technical skills and technologies.

### Projects
Showcase of personal and academic projects.

### Education
Academic qualifications and institution details.

### Contact
Email, LinkedIn, and GitHub links.

- Responsive Web Design
- CSS Layout Techniques
- Navigation Menus
- Portfolio Development
- User Interface Design
